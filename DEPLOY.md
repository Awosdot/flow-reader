# Flow Reader: get the APK (no coding tools needed)

1. Go to https://github.com/new while signed in as Awosdot.
2. Repository name: flow-reader. Keep it Public. Click Create repository.
3. On the new repo page click "uploading an existing file".
4. Unzip flow-reader.zip on any computer. Drag the CONTENTS of the folder
   (app, .github, build.gradle.kts, settings.gradle.kts, gradle.properties, .gitignore)
   into the upload box. If your browser hides the .github folder, turn on "show hidden files".
5. Click Commit changes. The build starts by itself (Actions tab, about 3 to 5 minutes).
6. When it is green, open this link on the tablet and install:
   https://github.com/Awosdot/flow-reader/releases/download/latest/flow-reader.apk
7. Allow "install unknown apps" for your browser when Android asks.

It installs next to Swipe Reader and Swipe Shelf (different app id, name and orange logo).
